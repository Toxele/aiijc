# Описание simclr_like_solution

Этот ноутбук смотреть не обязательно, но для истории приложил. Здесь мы использовали infoNCE подход, вдохновляясь вот этой статьёй: https://medium.com/self-supervised-learning/nt-xent-loss-normalized-temperature-scaled-cross-entropy-loss-ea5a1ede7c40. Эмбеддинги resnet50 и pointnet обучались вместе с общим лоссом. Как итог - получили идеальные эмбеддинги для stl, но эмбеддинги изображений начали "дрейфовать" на тестовых данных.

# Описание Notebook_1

После провала с resnet я решил сменить архитектуру на ViT (Visual Transformers) и попробовать новый лосс - SupervisedContrastiveLoss, но он требует разметки. Взяв уже хорошие веса для stl я выполнил разметку с помощью этого ноутбука. Перед обучением запустить его нужно обязательно.

# Описание Notebook_2

Здесь ноутбук чисто с обучением модельки, можно увеличить размер батчей / num_points / поиграться с оптимизатором.

# Описание Notebook_3

Ноутбук для отладки. Есть реализация tsne для test данных и можно просмотреть буквально все 200 запросов из папок queries наглядно. Должно быть очень удобно для просмотра качества модели. Запуск настроил под CPU, так что если будете запускать локально, то можете дообучать модель из второго ноутбука и параллельно на CPU смотреть как она работает.

# Про подходы

В обучении я размораживаю веса stl и дообучаю их с маленьким LR, а ViT - наоборот. Это нужно, чтобы лучше "сшить" модальности. Лосс на тех весах, что я прислал в тг - 0.32 за 27 эпох. Каждая эпоха 35-45 минут заняла на 3060 видюхе. В гит веса залить не могу, т.к. стоит ограничение на 25 мб памяти.

## 🧠 Стратегия обучения

**Подход к обучению:**
- STL веса: **разморожены** + дообучение с малым LR
- ViT веса: **заморожены** (обратная стратегия)
- Цель: оптимальное "сшивание" модальностей

**Результаты:**
- Достигнутый лосс: **0.32** за 27 эпох
- Время обучения: **35-45 минут/эпоха** на RTX 3060
- Веса модели: доступны в Telegram (ограничение GitHub 25 МБ)
